### What's New in Version 1.0.35 (Build 36):
1. **Out-of-Stock Orders Visibility & Warning Tags**:
   - Orders containing zero-stock items now remain completely visible across the Admin Web Orders and Stockage dashboards.
   - Out-of-stock items display amber/red warning badges and detailed stock alerts instead of silently filtering the entire order out.

2. **MR Location Attribution & Field Privacy Isolation**:
   - Medical Representatives only view the doctor/clinic locations marked by their own team/account on their personal field maps.
   - Marked locations feature explicit author attribution tags displaying the MR's name and ID.

3. **Route Batch Location Assignment**:
   - Territory route batches now support binding and grouping multiple verified clinic locations directly from the Admin Portal.
   - Mobile location pinning screen lets MRs select territory route batches on the fly.

4. **Multi-Location Monthly Tour Planning (TP)**:
   - Monthly TP planning screen allows selecting multiple clinic locations per calendar date with sequenced stop numbers (`STOP #1`, `STOP #2`, etc.).
   - Multiple locations are bundled and saved with full route batch context.

5. **Route Change Request Workflow**:
   - MRs can request mid-cycle route adjustments for already-approved tour plans via an in-app change request modal.
   - Management reviews and approves/rejects requests with instant reason notes and automatic plan updating.

6. **TP-Driven Geofenced Task Sequencing**:
   - Approved tour plan items automatically generate daily field tasks arranged in optimal stop sequence.
   - Geofence enforcement (`🔒 GEOFENCE LOCKED`) prevents attendance punch-in or task execution if the MR is outside the 50-meter perimeter.
